# Задание для продолжения

```text
Продолжи проект в текущем репозитории. Прочитай AGENTS.md, HANDOFF.md,
docs/AGENT_GUIDE.md и docs/COMPLIANCE.md, проверь состояние Git.
Сохрани текущую модель и submission перед экспериментами. Проверь сохранённую
модель и официальный список пар, если он получен.
Не меняй активную модель log_t0.75 без нового поручения. Проверки разных версий
разделены в docs/COMPLIANCE.md; повторяй их по мере изменения кода.
Сырые данные и локальные эксперименты не входят в репозиторий.
После этапа обнови HANDOFF.md и журнал экспериментов.
```
