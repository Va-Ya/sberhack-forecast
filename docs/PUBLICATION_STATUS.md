# Опубликованная модель

Активна `log_t0.75`: LightGBM, 400 деревьев, 65 признаков, 1200 пар на дату среза.
Модель и submission взяты из коммита `106ab67`, при правке документации не менялись.

Результаты исследований LightGBM, CatBoost и ансамблей сохранены в
`reports/research/`. Экспериментальный ансамбль не активирован.
Поддержка этих вариантов в коде не означает, что они используются текущей моделью.
