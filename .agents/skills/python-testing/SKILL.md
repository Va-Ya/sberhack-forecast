# python-testing

Use for meaningful Python contract and regression tests with pytest.
Cover aggregation, cutoffs, zero-safe metrics, deterministic predictions, input errors and CLI/API parity.
Use fixtures and parametrization; use tiny synthetic data for ordinary tests and a separate real-data smoke run.
Prefer a failing regression before a behavioral fix. Test observable outcomes, not mirrored implementation.
Run python -m pytest --basetemp .pytest-tmp. See references/upstream.md for optional testing techniques.
