# python-patterns

Use for implementing or reviewing Python.
Prefer explicit functions, dataclasses, type annotations, pathlib and context managers.
Handle specific failures, retain exception causes, stream large inputs and use NumPy/pandas vectorization.
Keep forecast transformations shared with app. Check with ruff and the project's pytest suite.
See references/upstream.md for examples; install no unrelated tooling from its examples.
