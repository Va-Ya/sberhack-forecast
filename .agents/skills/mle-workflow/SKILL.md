# mle-workflow

Use for reproducible forecasting, leakage checks, temporal validation and shared training/serving code.
Define the data/metric contract first. Compare temporal baselines and save all five official metrics.
Fit category metadata as of each origin. Record seeds, dependency versions, data hashes and model config.
Use native model artifacts, keep the previous working bundle, and update HANDOFF.md after milestones.
Consult references/upstream.md for broader ML guidance only when relevant; no feature store or online rollout is needed.
